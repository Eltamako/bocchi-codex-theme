# 2.15.1 · 上下边缘修复 / Header and footer seam fix

## 中文

这次是 2.15.0 的小修补丁，兼容版本和使用方式不变。

- 修复页眉下方的黑线、底栏遮住壁纸以及滚动条旁的竖缝。保留原来的明暗渐变、圆角、人物取景和输入框布局。
- 六款壁纸、STARRY 菜单、选择记忆、贴纸、Chat／Work 及多窗口功能继续保留。启动器仍为 1.3.1。
- 维护者已在正在使用的新版客户端确认修复后的显示正常；60 项公开版页面检查（含旧版对照）通过，解压包的 61 项运行回归、安装自检及独立安装通过。

**适配：Windows x64 · Codex 26.1117.41037（安装包 26.1117.4957.0）。**

下载 **Bocchi-Codex-Theme-2.15.1-windows-x64.zip**，完整解压到独立文件夹，双击 **01-安装.cmd** 或 **Install.cmd**。保存正在进行的工作并从托盘退出旧窗口后，使用桌面的 **Bocchi Codex Theme** 启动即可。六款壁纸与运行环境都已经包含在包内。

## English

This is a small follow-up to 2.15.0, with the same supported Codex build and installation steps.

- Removes the dark line beneath the header, the native footer paint covering the wallpaper, and the seam next to the scrollbar while preserving the existing gradients, rounded corners, framing, and composer layout.
- Retains all six wallpapers, the STARRY picker, saved selections, stickers, Chat/Work and multiwindow support. The launcher remains at 1.3.1.
- The maintainer confirmed the corrected appearance in the running desktop client. All 60 public-theme page checks (including baseline comparisons), 61 unpacked-package checks, the installation check, and an isolated fresh installation passed.

**Compatibility: Windows x64 · Codex 26.1117.41037 (package 26.1117.4957.0).**

Download **Bocchi-Codex-Theme-2.15.1-windows-x64.zip**, extract it into a separate folder, and run **Install.cmd**. Save your work and exit the old window from the system tray before launching **Bocchi Codex Theme** from your desktop. The complete package includes the six wallpapers and runtime.
