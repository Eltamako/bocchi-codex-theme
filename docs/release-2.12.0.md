# 2.12.0 · 新版 Codex Desktop 适配 / Updated Codex Desktop support

## 中文

六款《孤独摇滚！》壁纸现已适配新版 Codex Desktop，继续支持 STARRY 切换、选择记忆、多窗口和暂停恢复。

- 支持 **Windows x64**，适配 **Codex 26.1111.21308**（Windows 安装包 **26.1111.2228.0**）。
- 核对了新版窗口圆角和输入框材质。壁纸跟随原生圆角，输入框保留主题颜色。
- 首次启动回归覆盖托盘退出后接续启动、首屏加载较慢和重复点击。50 项页面模拟、两代 PowerShell 各 10 组检查、61 项解压包回归以及安装检查均通过。实机核对了安装与桌面入口，冷启动覆盖来自自动化回归。

下载 **Bocchi-Codex-Theme-2.12.0-windows-x64.zip**，完整解压后双击 **01-安装.cmd** 或 **Install.cmd**。保存工作并从托盘退出普通 Codex 后，用桌面的 **Bocchi Codex Theme** 启动即可。完整包包含运行环境。

仍在使用 Codex **26.1103.60933／26.1103.7773.0** 的用户可继续使用 [2.11.0](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.11.0)。素材来源与权利说明见仓库中的 **ASSETS.md**。

## English

All six Bocchi the Rock! wallpapers now support the updated Codex Desktop build. The release keeps the STARRY picker, saved selections, multiple windows, and pause and resume controls.

- Supports **Windows x64** with **Codex 26.1111.21308** (Windows package **26.1111.2228.0**).
- The wallpaper follows the updated native window corners, and the composer keeps the theme colors.
- Startup regressions cover launching after a tray exit, a slow first page, and repeated clicks. All 50 page fixtures, 10 suites under each PowerShell version, and 61 checks from the unpacked candidate passed. The installation and shortcut were checked on Windows. Cold-start coverage comes from automated tests.

Download **Bocchi-Codex-Theme-2.12.0-windows-x64.zip**, extract it, and run **Install.cmd**. Save your work and exit the regular Codex window from the system tray, then open **Bocchi Codex Theme** from your desktop. The Windows package includes the runtime.

Use [2.11.0](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.11.0) with Codex **26.1103.60933 / 26.1103.7773.0**. See **ASSETS.md** in the repository for artwork sources and rights.
