# 平台与验证边界 / Platform boundaries

Windows 2.7.0：主题 2.7.0，加载器 1.3.0，Codex 26.1021.31345 / Windows 安装包 26.1021.3705.0，x64。页面渲染、六款素材、动态 Chat、多窗口会话和共享选择事务沿用已确认实现。安装器新增文件清单核验与必要脚本下载标记处理。

源码仓库可以同时保存不同平台的代码。Windows 执行路径不能加载 Mac 专属模块；Windows 完整包按独立清单排除 Mac adapter、启动器与运行文件。源码共存测试检查真实模块加载与调用，包测试检查最终解压内容，两者不混用。

macOS Apple Silicon 在独立整合副本继续实验性开发。它保留自己的 app/build/arm64、签名、进程和端口检查；停止主题保留客户端。Mac 的单个合格主页面限制不影响 Windows 多窗口。当前 Windows 发行不声明 Mac 正式支持。

原生操作、人工反馈、历史记录与模拟测试分开记录，见[验证记录](验证记录.md)。未进行当前整合版 Mac 原生验收；远程 CI 未运行时不标为通过。

## English

Windows 2.7.0 targets Codex 26.1021.31345 / package 26.1021.3705.0, x64, with loader 1.3.0. Confirmed visuals, dynamic Chat detection, multiwindow sessions and shared selection transactions are retained. Setup adds manifest verification and scoped download-marker handling.

Platform source files may coexist. Windows execution must not load Mac-only dependencies, and the Windows ZIP excludes Mac-specific files. Dependency probes and extracted-package tests enforce these distinct requirements.

Apple Silicon integration remains experimental and separate. Its app/build/architecture, signature/process/socket checks and stop-without-closing-client behavior are preserved. Its one-eligible-main-page restriction does not reduce Windows multiwindow support. Current integrated Mac source has not undergone native acceptance.
