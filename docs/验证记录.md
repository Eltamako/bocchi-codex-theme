## 本轮自动化检查

- Windows 源码 Node 回归 **52/52 通过，无跳过**。包含多窗口发现、逐窗恢复、独立 heartbeat、共享壁纸事务及动态 Chat 识别。
- Windows PowerShell 5.1 和 PowerShell 7 各 **10 组**隔离测试通过：安装发现、Unicode 快捷方式、实例与就绪保护、启动、重复启动、安装归属、退出清理、发行文件完整性、来源标记边界。新增两组分别检查 22 项和 20 项。
- 平台边界测试允许源码共存，实际监测 Windows 路径的模块加载、adapter 读取和平台调用；主动引入静态／动态 Mac 依赖、Mac adapter 读取和平台命令的四类反例均被发现。Windows ZIP 另做严格的 Mac 专属文件排除检查。
- 源码素材与清单检查通过。本轮没有修改 renderer、runtime、壁纸参数、CSS 或图片；这些文件用哈希关联此前验收，不重新声称做了一轮全部视觉测试。

## 下载来源标记模拟

- 在独立测试目录给无害脚本添加互联网来源标记，Windows PowerShell 5.1 的 RemoteSigned 确实拒绝执行。通过测试位置的 Unicode 快捷方式，在解除该脚本标记后成功启动无害探针；没有启动第二个真实客户端。
- 实际安装器在隔离副本中通过 CheckOnly、篡改拒绝、遗漏依赖拒绝、安装和重复安装五个场景。CheckOnly 不写配置或移除标记；失败时保持标记；成功仅解除完整清单核验后的 14 个必要生产脚本，其他脚本保持原样。
- 使用的解压工具没有将测试 ZIP 的来源标记传播到文件，因此又显式标记测试文件来验证保护。这是“来源标记模拟”，不是浏览器下载后首次运行的完整实机证明。
- 执行策略只对已获授权的独立测试进程设置为 RemoteSigned；系统、当前用户和组织策略保持不变。桌面入口继续使用 RemoteSigned。
