## 本机确认

- 本次版本变化提示来自仍指向 2.4.0 的旧中文桌面入口。对照 GitHub v2.6.0 的安装脚本，确认缺少该旧入口的迁移处理；不是取消客户端版本检查。
- 旧入口已按字节备份，迁移后桌面保留新版 Bocchi Codex Theme。旧安装目录保留。
- 用户从托盘退出后，手动打开新版桌面图标，确认壁纸出现。启动记录显示无其他客户端时启动成功，加载主题 2.6.1，图片已加载，壁纸选择保留。此次启动记录约 18 秒，不作为所有机器的速度保证。
- Chat 的实际图片预览会卸载旧输入框并创建图片编辑输入框。修复后在用户指定图片上完成打开、关闭、再打开；同一主题实例及壁纸层全程保留。主画面和标题栏原生圆角匹配，STARRY 无光晕。
- 普通客户端仍打开时的保护已实际触发并核对进程，未强制关闭窗口。此前一次“点击无反应”没有新的入口记录，不能独立认定其原因；后续用户实际点击启动已成功。
