- 新增启动检查 24 项：托盘退出期间的等待、已验证的无窗口主题进程、外部进程隔离、身份变化、Start／Resume 复用路径。

## 实机证据与边界

本机原有安装应用同一启动修复后，用户已确认壁纸加载成功；启动记录核对到后台退出完成、同一窗口就绪和重复点击的时间重叠。重复点击修复另以独立进程测试，并只读确认当前真实主题满足复用条件。没有为了发布而重启正在使用的客户端。

这些证据不代表已在另一台机器或真实英文 Windows 上完成 2.5.1 整包验收。本次没有重跑完整页面矩阵，因为壁纸、取景及渲染行为未改动；下方保留的页面结果属于 2.5.0。真实超时、登录、兼容性及身份异常仍会报错。

本机运行配置、启动记录、聊天、账号及测试产物不进入发行包。README 两张实机图保持原样，来自已授权的 2.4 中文界面。

## 验证边界

上述页面和自动外观检查使用独立模拟页面，不能代替真实发送、原生滚动、侧边聊天及完整英文 Windows 的验收。本轮未在真实英文 Windows 上完成整套安装和客户端交互验证，也没有切换当前正在使用的客户端外观。本机现有主题／加载器文件已比对保持不变。

README 使用两张用户授权公开的 2.4 实机截图；它们不代表 2.5 英文界面实机验证。模拟截图、网友照片、账号、聊天、本机配置及测试产物不进入发行包。

网友照片中的错误与旧版浅色限制相符，但未取得对方机器状态，不能认定唯一原因或归咎于操作。新版自动深色解决已复现的这一种触发条件；未登录、版本不匹配等情况仍会保留明确提示。

发布前已保存固定中英文搜索词的 GitHub 查询快照。简介、标签和双语文档有助于检索与安装，但不承诺排名或收录时间。压缩包及发布附件的核对结果以本次发行记录和 SHA256 校验文件为准。
