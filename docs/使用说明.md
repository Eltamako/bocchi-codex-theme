# 使用说明

[English guide](en/install.md)

## 在新窗口中使用

从主题入口启动后，在本地任务菜单选择“在新窗口中打开”，壁纸会随任务页面自动加载。每个窗口都可以使用 STARRY 切换；当前其他窗口的画面会保留，新窗口则沿用最近一次成功保存的选择。

Pause.cmd 会暂停全部主题窗口，Resume.cmd 会为它们重新加载最近保存的壁纸。关闭一个窗口不会关闭其他窗口或清除其壁纸。当前验证范围为本地任务窗口及其中的 Chat／Work 页面；悬浮角色、浏览器等辅助窗口保持原样。

## 第一次安装

先正常安装并打开一次官方 Codex 桌面客户端，再完整解压 Windows 主题包。选择自己可以写入的文件夹，尽量不要放进 WindowsApps、Program Files 或临时下载缓存。

双击 `01-安装.cmd` 后会出现一个文字窗口。检查通过后，它会生成 `installation.json`、本地数据目录 `.local`，以及桌面上的 `Bocchi Codex Theme` 快捷方式。安装只做准备，不会立即切换当前窗口，也不会关闭你正在使用的客户端。

如果桌面已有能确认归属的旧主题入口，安装器会先备份到本包的 `.local/backups/shortcut-时间/`，再更新。无关或已损坏、无法确认归属的同名入口会保留并提示，不会直接覆盖；请自行保留并改名后重试。

然后打开 `02-启动主题.cmd`。主题使用独立的客户端配置目录，因此可能会出现登录页。请直接在官方页面完成登录；账号密码无需写入主题文件。进入 Chat 或 Work 后，主题会临时使用深色显示；暂停主题时恢复原外观。浅色、深色和跟随系统的长期偏好都保持原样。首次登录花费较长时间时，启动器可能先提示未确认加载，登录完成后再运行一次 `04-恢复主题.cmd` 即可。

## 六款壁纸

右上角的 STARRY 是切换入口。打开后会显示六款缩略图和当前选中标记，Chat 与 Work 共用选择，重启后也会保留。

1. 下北泽夜场：保留最初的排练结束场景。
2. 四色肖像 · 夜场切片：四人的肖像与夜场配色。
3. 演出散场 · 后台合影：合影、场地和柔和的地面反光。
4. 波奇失重 · 乐器宇宙：保留白色贝斯、大鼓和漂浮的乐器元素。
5. 冬日候场 · 暖灯店门合照：冬装四人与暖灯店门。
6. 随身节拍 · 四色合拍：耳机、四色线条与碎色背景。

可以用鼠标点击，也可以聚焦 STARRY 后用键盘操作。按 Esc 或点击菜单外部可关闭，焦点会回到标牌。快速连续选择时会以最后一次选择为准。

## Chat 和 Work

Chat 的场景更明显，Work 的阅读遮罩更深。首页纸箱波奇位于标题与输入框之间，四人贴纸位于左下空位。输入框发饰会一部分贴在框内，一部分露在外面。

窄窗口、右侧预览、弹窗和长对话会影响装饰可用的空位。贴纸会先缩小，仍放不下时收起，尽量保留文字和按钮周围的空间。STARRY 会单独保留可访问的位置。

菜单、代码和工具卡片继续使用适合阅读的底色。透明表格保留文字和细分隔线；看到原生功能卡片时仍按客户端原本的方式操作即可。

## 暂停与继续

想暂时看原来的界面，可以双击 `03-暂停主题.cmd`，留几秒让窗口移除主题。它不会关闭当前对话。想继续使用时打开 `04-恢复主题.cmd`，上次选的壁纸会回来。

要完整结束主题会话并回到普通客户端，请先保存还没发送的草稿，再运行 `05-恢复原界面.cmd`。详细区别见 [恢复与回退](恢复与回退.md)。

## 文件夹里的入口

`01` 用于首次配置或重新建立桌面入口；`02` 用于平时启动；`03` 和 `04` 用于暂停、恢复；`05` 用于回到普通客户端。每个入口结束后会保留文字窗口，方便看结果，按任意键即可关闭。

这几个入口只在本次 PowerShell 进程中使用执行策略参数，不修改系统的长期执行策略。组织管理的电脑如果限制脚本运行，请沿用组织提供的软件使用方式。


## 升级与已有窗口

新版使用独立目录。启动前先保存草稿并退出普通 Codex 主窗口，再打开主题入口；启动器不会替你关闭另一个正在工作的窗口。手机端若提示会话占用，确认连接到当前主题窗口。升级、选择迁移与回退见 [恢复与回退](恢复与回退.md)。

## 中英文与语言设置

打开 `06-语言设置.cmd` 或 `Language.cmd`，选择自动、简体中文或 English；直接按回车保留当前设置。自动模式下，安装工具跟随 Windows，菜单优先跟随客户端页面语言；中文环境使用简体中文，其余使用英文。手动选择只保存到本主题的本地配置，不改系统或官方客户端语言。

中文与英文入口共用同一实现，英文文件名不会强制改用英文。需要指定时，可在终端运行 `Install.cmd -Language en`、`Start.cmd -Language zh-CN` 或 `Language.cmd -Language auto`。安装脚本和启动脚本也接受同样的语言参数。


2.6.0 启动提醒：从托盘选择 Exit 后，可直接打开主题入口；启动器会等候退出完成。重复点击会等待已在进行的操作。新版请解压到独立文件夹，保留旧版用于回退。

## 下载来源标记

请从项目发行页取得完整包，并按 SHA256SUMS.txt 核对 ZIP。安装器会核对发行清单中的文件内容与路径，再仅处理清单内 PowerShell 脚本的下载标记，帮助桌面入口正常启动。其他文件和系统执行策略保持原样；组织策略仍然有效。

如果文件缺失、内容变化或标记处理失败，安装会给出诊断信息。请重新解压完整包后重试，不需要关闭安全软件。高级检查参数 `安装.ps1 -CheckOnly` 只核验，不移除来源标记、不建立配置或快捷方式。来源标记修复采用隔离模拟验证，尚未覆盖所有浏览器和解压工具组合。
