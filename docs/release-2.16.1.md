# 2.16.1 · Work 首页修复 / Work home fix

## 中文

2.16.1 修复部分 Work 首页不显示壁纸和 STARRY 菜单的问题。主题会根据新版的模式切换和输入框结构识别 Chat、Work 及任务页面。

- Work 首页和任务对话都已在当前客户端确认可以显示壁纸。页面回归覆盖 Chat／Work 切换、图片预览、输入框和上下边缘。
- 六款壁纸、选择记忆、贴纸和任务多窗口继续可用。首次启动、重复双击和桌面快捷方式均通过回归。

适配 **Codex 26.1120.50957**，Windows x64 安装包 **26.1120.6357.0**，加载器 **1.3.1**。

下载 **Bocchi-Codex-Theme-2.16.1-windows-x64.zip**，解压到新文件夹后运行 **01-安装.cmd** 或 **Install.cmd**。安装会更新可确认归属的桌面入口。保存工作并从托盘退出旧窗口，再打开 **Bocchi Codex Theme**。

## English

2.16.1 fixes a Work home layout that prevented the wallpaper and STARRY picker from loading. The theme now recognizes the updated mode switch and composer layout on Chat, Work, and task pages.

- Work home and a Work conversation were confirmed in the running desktop client. Regression tests cover mode switching, image previews, composer layout, and header and footer seams.
- The six wallpapers, saved selections, stickers, and task windows are all available as before. First launch, repeat clicks, and desktop shortcut regressions passed.

Supported build **Codex 26.1120.50957**, Windows x64 package **26.1120.6357.0**, launcher **1.3.1**.

Download **Bocchi-Codex-Theme-2.16.1-windows-x64.zip**, extract it to a new folder, and run **Install.cmd**. Setup updates an existing desktop shortcut if it belongs to the theme. Save your work, exit the old window from the system tray, and open **Bocchi Codex Theme**.
