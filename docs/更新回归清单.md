# 更新时容易复发的问题

这份清单整理已遇到的真实问题。适配时先对照当前客户端结构，再运行相关回归；没有变化的素材和渲染算法沿用已确认版本。

## 启动与安装

| 曾经的现象 | 保留的处理方式 | 检查入口 |
| --- | --- | --- |
| 托盘 Exit 后，第一次打开提示找不到进程 | 旧 PID 已退出且端口已释放时，同一次点击接续启动；不把消失的进程当永久错误 | `startup.test.ps1`、真实首次启动 |
| 页面还在登录或加载，稍后壁纸出现但先弹失败 | 精确记录 `waiting-for-page` 并继续等待；身份、布局或渲染错误仍分别报告 | `readiness.test.ps1`、`runtime-install.test.mjs` |
| 双击两次出现“另一操作正在进行” | 合并重复操作并激活现有窗口，保留原会话 | `duplicate-start.test.ps1` |
| 启动状态文件短暂不存在或被占用 | 仅对已复现的短暂读取竞态有限重试 | `runtime-start-state.test.mjs` |
| 更新后桌面入口仍指向旧版、中文路径损坏或变成 PowerShell 图标 | 验证原快捷方式归属，Unicode 读写并保留本机图标 | `shortcut.test.ps1`、桌面入口核对 |
| 从浏览器下载后被脚本策略阻止 | 安装器完成路径、清单和哈希核验后，仅解除清单内必要脚本的下载标记 | `package-integrity.test.ps1`、`package-origin-edge.test.ps1`；模拟不等于真实下载 |
| 客户端自动更新后版本不匹配 | 读取注册包和应用归档的实际版本，适配新结构；不放宽版本或进程身份校验 | `discovery.test.ps1`、安装 CheckOnly |
| 浅色客户端没有壁纸 | 临时使用深色外观，暂停恢复原外观；不修改长期偏好 | renderer 外观恢复检查 |

## 页面与画面

| 曾经的现象 | 保留的处理方式 | 检查入口 |
| --- | --- | --- |
| 输入框上沿黑缝、旁边黑块 | 只清除已确认的空白原生底栏绘制层，覆盖其兄弟分支；不清空整个父容器 | renderer 底栏、变高及暂停恢复检查 |
| 输入框下面露正文 | 正文按实际底栏上缘裁切，附件、多行和请求卡片变化时更新；保留滚动高度 | renderer Chat/Work 展开输入框检查 |
| 首页标题和模式切换偏右、贴纸压工具栏 | 对齐同一个输入列；纸箱以整列工具栏上缘定位，保留原生 Codex 图标 | renderer 全局/项目首页、窄窗口检查 |
| 首页偏低、打开项目菜单时上下跳动 | 限量整体上移；菜单只影响装饰可见性，不撤销布局 | renderer 四种尺寸、菜单开关、返回对话检查 |
| Chat 表格偏右 | 修正内层表格 viewport 的重复横向 padding，保留横向滚动 | renderer 表格及恢复检查 |
| Chat / Work 打开图片壁纸消失 | 区分同一输入框移入查看器、Chat 替换输入框、关闭动画，保留完整场景 | renderer 两种模式图片预览检查；实机另记 |
| 侧栏开关导致断层或卡顿 | 场景使用同一布局原子提交，缓存稳定尺寸并取消过时绘制 | renderer 尺寸切换；实机连续开关 |
| 左上角变方、STARRY 周围新增光晕 | 沿用原生外框圆角和现有无光晕按钮样式 | 原生外框核对；样式保持哈希 |
| 顶部齐刷刷变黑、耳机底边出现黑带、人物被压暗 | 保留环境连续、背景内压暗和按窗口边缘收尾；不重新生成或移动素材 | 六壁纸目标图哈希、构图和场景完成检查 |

## 多窗口与发布

| 曾经的现象 | 保留的处理方式 | 检查入口 |
| --- | --- | --- |
| 新窗口没有壁纸、关闭一个窗口影响其他窗口 | 同一受信客户端发现多个页面，每窗独立恢复与 heartbeat，共享选择事务 | `multiwindow.test.mjs`、`wallpaper-store.test.mjs` |
| 手机提示另一个会话占用任务 | 避免重复独立 Desktop 主实例，保留同一实例内的多窗口；不操作远端任务锁 | `startup.test.ps1`；手机端到端需另行实测 |
| 测试款或 Mac 文件误入 Windows 包 | 公开目录固定六款；私人测试素材与 Mac 运行时独立；构建后核对实际 ZIP | 资源检查、Windows 平台边界及 ZIP 清单 |
| 文档或桌面安装与发布包不一致 | 从最终源码重算清单，解压最终 ZIP 检查安装；保存原安装与回退入口 | `check-assets.mjs`、最终 ZIP SHA256、CheckOnly |

`tests/` 是自动化回归，`tools/test-renderer.mjs` 使用模拟页面。截图只有在目标壁纸完成绘制并核对原图哈希后才生成。模拟结果不写成实机保证；本次结果以[验证记录](验证记录.md)为准。

## 画面与协作约定

- 六款壁纸、人物取景、既定压暗强度、输入框颜色和两张公开实机图继续保留。
- 新版只改确有变化的适配点；共享 renderer/runtime 不为版本更新做整体重构。
- Windows 多窗口、进程/端口身份检查及用户数据保护不能因 Mac 准备而退化。
- Mac 分支保持独立审阅；Windows 包不装入未经原生验证的 Mac 运行时。
- 切换主题、暂停和恢复应还原对应属性；不改聊天内容、账户、系统语言或官方安装文件。
