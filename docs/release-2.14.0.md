# 2.14.0 · 新版 Codex Desktop 适配 / Updated Codex Desktop support

## 中文

六款《孤独摇滚！》壁纸已适配新版 Codex Desktop。更新后仍可以使用熟悉的桌面入口、STARRY 切换、壁纸记忆、角色贴纸和多窗口功能。

- 支持 **Windows x64**，适配 **Codex 26.1117.31558**（Windows 安装包 **26.1117.3838.0**）。
- 适配新版页眉背景，保留原生圆角、壁纸取景、渐变、阅读区和输入框的原有样式。
- 51 项页面模拟、两代 PowerShell 共 20 组回归、61 项解压包回归和独立安装均通过，包括首次加载慢、托盘退出接续和重复启动。真实桌面冷启动仍待实机确认。

下载 **Bocchi-Codex-Theme-2.14.0-windows-x64.zip**，完整解压后双击 **01-安装.cmd** 或 **Install.cmd**。保存工作并从托盘退出普通 Codex 后，通过桌面的 **Bocchi Codex Theme** 启动即可。完整包已经包含运行环境。

仍在使用 Codex **26.1111.71704／26.1111.9664.0** 的朋友，请继续使用 [2.13.0](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.13.0)。素材来源与权利说明见仓库中的 **ASSETS.md**。

## English

All six Bocchi the Rock! wallpapers now support the updated Codex Desktop build. Keep using the familiar desktop entry, STARRY picker, saved selections, character stickers, and multiple windows.

- Supports **Windows x64** with **Codex 26.1117.31558** (Windows package **26.1117.3838.0**).
- Adapts the new sticky header background while retaining native corners, wallpaper framing and gradients, the conversation area and composer styling.
- All 51 page fixtures, 20 suites across two PowerShell versions, 61 unpacked-package regression checks, and an isolated fresh installation passed. The startup checks cover slow page loading, launching after a tray exit, and repeated clicks. A native desktop cold start remains to be confirmed.

Download **Bocchi-Codex-Theme-2.14.0-windows-x64.zip**, extract it, and run **Install.cmd**. Save your work and exit the regular Codex window from the system tray, then launch **Bocchi Codex Theme** from your desktop. The Windows package includes the runtime.

Use [2.13.0](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.13.0) with Codex **26.1111.71704 / 26.1111.9664.0**. See **ASSETS.md** for artwork sources and rights.
