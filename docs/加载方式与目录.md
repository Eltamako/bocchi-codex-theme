# 加载方式与目录

## 启动过程

1. 安装器核对 Node 的 SHA256，校验六组壁纸与贴纸，读取官方客户端的应用版本和 Windows 包版本。
2. 在主题目录内创建本机配置和 `.local` 数据目录。
3. 启动时使用已安装的官方程序，并传入专用的 user-data-dir。调试连接只绑定 `127.0.0.1:9347`。
4. 加载器核对监听进程、程序路径、专用配置目录、进程创建时间与浏览器会话身份，然后只连接识别到的主页面。
5. 注入器检查活动页面和必要界面标记，加载 CSS、壁纸及装饰；通过短期租约维持主题。
6. STARRY 提交六个固定壁纸 ID 中的一个。加载器保存本地选择，并返回这次请求的回执。图片解码成功后再切换，不接收任意文件路径。

可选的 `theme/wallpapers/<ID>/environment.png` 记录在 `environment` 中，通过 `nativeSize` 与 `mainRect` 对齐主图。只读取清单中固定目录内的图片；加载失败时保留此前有效目录与画面。

图片缓存会复用；切图不会重新载入页面。暂停时移除主题节点、监听器和图片资源。普通客户端的安装文件与配置不会被覆盖。

## 目录

| 路径 | 用途 |
| --- | --- |
| `release.json` | 发行版本、适配范围、Node 校验值 |
| `installation.json` | 安装后生成的本机路径；不应提交到仓库 |
| `engine/` | 本地加载器、运行环境与第三方许可 |
| `theme/renderer.js`、`theme/theme.css` | 页面适配与可编辑样式 |
| `theme/adapter.json` | 支持的版本及页面标记 |
| `theme/wallpapers.json` | 六款壁纸清单与各自取景参数 |
| `theme/wallpapers/<ID>/main.png` | 主图；六款均为 1672 × 941 原生母版 |
| `theme/wallpapers/<ID>/background.png` | 配套底景，尺寸按实际文件记录 |
| `.local/wallpaper-selection.json` | 上次选择，与暂停控制分开保存 |
| `.local/managed-profile/` | 主题专用客户端登录和本地设置 |
| `.local/backups/` | 安装器备份的同名桌面入口 |
| `.local/runtime-state.json`、`control.json`、`status.json` | 当前加载器状态；不用于迁移 |
| `docs/` | 使用、恢复、开发和验证说明 |

这套发行包没有自动更新、上传日志或遥测接口。运行时使用本地回环连接；官方客户端自身的网络功能保持原样。图片真实尺寸和 SHA256 见 [素材清单](asset-manifest.json)。
