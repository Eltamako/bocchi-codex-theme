# 常见问题

[English troubleshooting](en/troubleshooting.md)

## 下载后找不到安装入口

完整包中会有 `01-安装.cmd`。如果是 GitHub 的源码下载，程序和图片都在，但不带 Node 二进制；使用 Releases 中的 Windows 完整包会更方便。

## 提示客户端版本不匹配

本版对应应用版本 26.1021.31345、Windows 安装包版本 26.1021.3705.0。自动更新后，页面结构可能变化，主题会先停止应用。可以使用普通客户端，等适配新版，不需要修改官方安装文件。

## 提示端口占用，或看到旧壁纸

通常是另一份主题仍在运行。先到旧主题目录执行“恢复原界面”，再从这份主题启动。不要同时运行多个壁纸注入器。如果不清楚占用来源，可以保留报错文字，在 Issue 中说明启动过哪些版本。加载器不会接管无法核对身份的窗口。

## 第一次登录后仍没有壁纸

先确认已经进入 Chat 或 Work，再运行 `04-恢复主题.cmd`。首次登录可能超过启动器等待时间，登录后重新恢复即可。版本或页面标记仍不匹配时，可以把版本号和报错发到 Issue。

## PowerShell 提示 Get-FileHash 不存在

完整包带有针对 Windows PowerShell 模块路径的修正。请通过编号入口启动，避免只复制部分脚本。仍有问题时，重新解压同版完整包，并记录报错内容。

## 图没有加载、切换失败

先确认整包已经解压，`theme/wallpapers` 里的六组主图、底景、五张环境图和两个贴纸文件都还在。素材损坏时重新解压即可；已有有效壁纸时，切换失败会尽量保留此前选择。

## Work 发送时闪回原界面

这一版保留了发送过渡修复：在同一已核对的 Work 页面中，编辑器短暂重建时最多保留主题 1 秒。早期版本的实机记录曾验证三轮发送；本版的回归范围另见 [验证记录](验证记录.md)。若遇到新的场景，请注明是首次发送还是跟进发送、是否出现确认卡，以及当时是否打开了右侧面板。

## 小窗口贴纸不见了

贴纸会按空位逐级缩小，最小宽度为 32 像素。空间不足、面板或弹窗占位时仍可能隐藏，目的是给正文和控件留出间距。可以稍微加宽窗口或收起面板再看看。

## 想反馈问题，哪些信息有用

客户端版本、主题发行版本、Chat／Work 模式、复现步骤，以及去掉私人内容的截图就很有帮助。本机 `.local/status.json` 与 `.local/last-operation-error.json` 可辅助定位；发送前先去掉其中的用户名、文件路径和会话标识。无需上传整个 `.local` 文件夹，它包含登录配置。


## 安装成功，启动却提示 renderer did not confirm

安装检查通过，说明包内文件和客户端版本通过了检查，并不代表当前页面和外观已就绪。2.4 在浅色外观下也可能只显示这句超时提示；2.5 会在已识别的 Chat／Work 页面自动使用深色显示，避免因为浅色外观而拒绝加载。暂停后恢复窗口原外观，不修改长期外观配置。

首次登录、页面还在加载或尚未进入 Chat／Work 也可能导致未就绪。请先完成登录、进入首页，再恢复主题。未知页面不会直接被认定为浅色问题。没有网友机器的诊断记录，不能仅凭这句提示判断原因。2.6.0 会保留与本次请求匹配的诊断，并分别提示连接、加载器退出或页面结构问题；请将主题版本、客户端版本和诊断原因一起提供。


## 壁纸已出现，却提示 Another theme operation is in progress

这通常是第一次启动还在进行时，又点了一次主题入口。2.6.0 会让后一次请求等待，并核对第一次是否确实成功，再复用当前窗口。启动时点一次、给它一点加载时间就好；如果已经重复点击，也无需重装。等待超过 90 秒仍未结束时，会明确说明这次请求尚未执行，不会假报成功。

## 已经在托盘选择 Exit，仍提示 Codex 没有退出

托盘退出可能需要一点时间。2.6.0 会等待最多 20 秒，并区分仍可见的普通窗口、未退出的后台进程和暂时无法核实的状态。之后直接使用主题入口，不用先打开普通 Codex。已经验证属于本主题的后台进程会被复用，不会因窗口暂时关闭而被误认为另一个客户端。

如果按此操作仍然报错，可以保留提示与本机 `.local/startup-attempt-*.json`，提供主题版本、客户端版本和复现步骤。记录只含启动阶段、时间、相关进程及窗口状态，不记录聊天内容；分享前仍请检查并去除不希望公开的信息。无需删除聊天数据或重装客户端。

## 查看图片时背景短暂消失

2.6.0 保留原版图片查看器的透明底色与动画，不再给全屏查看器填上普通菜单的暗底。查看同一对话的图片时，已加载的壁纸保持不变；暂停主题或离开支持的页面仍会正常清理。此项模拟检查与实机验证范围见[验证记录](验证记录.md)。


## 旧桌面入口提示客户端版本变化

如果运行中的新版主题正常，但退出后点击桌面旧图标报错，可能是图标仍指向旧安装目录。请运行与当前客户端匹配的新版 Install.cmd／01-安装.cmd，然后使用 Bocchi Codex Theme。2.6.1 会备份并迁移已确认归属的旧中文入口；备份在新版 `.local/backups/shortcut-*/`，旧安装目录保持不变。同名但无法确认归属的入口不会被改动，请核对其属性。若使用新版 Start.cmd 仍提示版本变化，请核对实际客户端与发行页适配范围，不要改版本号绕过检查。

## CMD 能启动，桌面入口没有响应

请先确认使用的是本版安装器并完成安装。下载来源标记可能影响 RemoteSigned 脚本启动；本版在文件清单验证后处理必要脚本的标记。若提示文件校验失败，请重新下载、完整解压并核对 ZIP 哈希。不要全局关闭执行策略或安全软件。[安装说明](使用说明.md)
