# 恢复原界面与退回旧版本

[English guide](en/upgrade-restore.md)

可以先按自己想要的效果选择下面的方法，不需要一开始就删除文件。

## 只想暂时隐藏壁纸

双击 `03-暂停主题.cmd`，等几秒即可。当前窗口、对话和登录状态会保留。以后再运行 `04-恢复主题.cmd`，就能继续使用原来选中的壁纸。

## 想回到普通客户端

1. 先复制或保存尚未发送的草稿，等当前任务处理到方便停下的位置。
2. 双击 `05-恢复原界面.cmd`。
3. 启动器会停止自己的加载器，移除主题，并关闭经过身份核对的主题专用窗口，然后打开普通客户端。
4. 以后从开始菜单里的官方入口打开即可。想再用主题时，仍可使用主题桌面入口。

主题运行时只借用当前窗口的深色显示；暂停、恢复原界面或加载器失联后，会撤销这项临时处理。主题没有修改普通客户端的外观配置，所以这里不需要把旧配置覆盖回去。普通窗口和主题专用窗口使用不同的本地配置，字体、登录状态或外观偏好可能各自保留。

## 入口失效、客户端刚更新，怎么办

如果恢复入口提示窗口身份或安装包已经变化，可以先关闭主题专用窗口，再从开始菜单打开官方客户端。不要为了停主题去结束所有同名进程，也不用删除聊天数据。

若窗口仍停留在主题状态，可以手动退出主题专用窗口后再打开普通客户端。加载器的主题租约约为 12 秒；加载器停止且页面仍在运行时，租约到期也会移除主题。下次使用匹配版本的完整包重新启动即可。

## 升级时怎样保留旧版本

1. 在旧版里执行“恢复原界面”，结束旧主题会话。
2. 保留旧版本整个解压目录，先不要覆盖或移动它。已有快捷方式依赖原来的目录位置。
3. 将新版完整包解压到另一个文件夹，运行新版的 `01-安装.cmd`。
4. 如果想沿用壁纸选择，在首次启动新版前，把旧版 `.local/wallpaper-selection.json` 复制到新版 `.local/`。2.6.1 保留 2.4 的六个 ID，2.3 的四个 ID 也继续有效。回退到 2.3 初版前，选择该版本支持的四款之一。
5. “恢复原界面”会打开普通客户端；启动新版主题前，请先保存草稿并退出这个普通窗口，再运行新版。新版使用自己的本地配置，可能需要重新登录一次。

只复制壁纸选择就够了。主题语言可以在新版的“语言设置”里重新选择。运行状态、进程编号、控制文件和整个登录配置目录都不用于版本迁移。

## 新版不合适，退回旧版本

1. 先在新版运行 `05-恢复原界面.cmd`。
2. 保存草稿并退出刚打开的普通客户端，再打开之前保留的旧版目录，运行旧版 `02-启动主题.cmd`。
3. 如果旧版也带有本发行方式的安装入口，再运行旧版 `01-安装.cmd`，让桌面入口重新指向它。更早的私人安装包可继续使用它原来的启动入口。
4. 确认旧版正常后，再决定是否保留新版文件夹。

如果是客户端已经更新，旧主题也可能因版本不匹配而暂停。这种情况先使用普通客户端，等待新的适配版即可，改版本号本身不能完成适配。

## 完全不再使用

先执行“恢复原界面”，确认普通客户端正常打开。随后可以删除主题创建的桌面快捷方式，并把整个主题解压目录移到回收站。

目录中的 `.local/managed-profile` 保存主题专用窗口的本地登录和设置；随目录删除后，未来再用主题可能需要重新登录。这个操作不会删除账号云端的聊天记录，也不会清理普通客户端的配置。还不确定要不要删时，保留文件夹即可，它没有开机自启。

若安装时备份过同名桌面入口，可以从 `.local/backups/shortcut-时间/` 复制回桌面。恢复前先确认那个入口所指向的旧文件夹仍然存在。

## 客户端版本对应

2.6.1 用于 Codex 26.1016.51333／26.1016.6573.0；2.5.1 用于 Codex 26.1013.40934／26.1013.4894.0。回退主题需要匹配客户端版本。请勿把旧运行状态复制到新版；只迁移壁纸选择。


## 旧桌面入口提示客户端版本变化

如果运行中的新版主题正常，但退出后点击桌面旧图标报错，可能是图标仍指向旧安装目录。请运行与当前客户端匹配的新版 Install.cmd／01-安装.cmd，然后使用 Bocchi Codex Theme。2.6.1 会备份并迁移已确认归属的旧中文入口；备份在新版 `.local/backups/shortcut-*/`，旧安装目录保持不变。同名但无法确认归属的入口不会被改动，请核对其属性。若使用新版 Start.cmd 仍提示版本变化，请核对实际客户端与发行页适配范围，不要改版本号绕过检查。
