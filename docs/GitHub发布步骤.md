# GitHub 发布步骤

这份交付已经分成源码包和 Windows 完整包。两者承担不同用途：仓库里放源码和文档，Release 附件放给使用者下载的完整包。

## 1. 准备仓库

可以使用仓库名 `bocchi-codex-theme`。简介可写：

> 《孤独摇滚》Codex 桌面主题，四款壁纸、STARRY 切换与 Chat／Work 适配。

创建空仓库后，将源码包解压出来的内容放到仓库根目录，确保首页能直接看到 README.md。不要把整个源码压缩文件作为唯一的仓库内容。

本地使用 Git 时，按 GitHub 空仓库页面给出的地址推送即可；也可以通过网页上传源码目录中的文件。Node 运行文件留在 Release 完整包里。

## 2. 检查这次要公开的内容

代码许可、第三方说明和素材说明已经分别写好。完整包包含四款动漫壁纸与贴纸；素材的具体再分发许可仍需要维护者核对，详见 ASSETS.md。官方公开与 AI 制作记录不自动替代授权信息。GitHub 对知识产权内容的要求可见 [GitHub 使用政策](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies#3-intellectual-property-authenticity-and-private-information)。

本次源码仅附上指定的两张实机演示截图，展示主题制作对话与首页；没有包含登录目录或其他项目记录。今后更新时，也可以沿用同样的文件清单。

## 发行说明

这一版把下北泽夜场、四色肖像、演出散场和波奇失重放进同一套主题里。点击右上角 STARRY 就能切换，Chat 和 Work 共用选择，重启后也会记住。

首页保留纸箱波奇，左下角是四人连体贴纸，输入框边缘带有小发饰。窄窗口会自动调整装饰，Work 的阅读区域会更深一些。

本版同时包含小窗口贴纸和 Work 发送时主题短暂闪回的修复。

适配范围为 Windows x64，客户端应用版本 26.1007.71326、Windows 包版本 26.1007.9446.0。下载 Windows 完整包、完整解压，双击 01-安装.cmd，再运行 02-启动主题.cmd 即可。首次使用可能需要在官方页面重新登录。

想暂时隐藏主题可以使用 03-暂停主题.cmd；想回到普通客户端可以使用 05-恢复原界面.cmd。详细步骤与旧版本回退方法都在包内 docs 目录。

程序使用 MIT 许可；素材来源与许可范围请见 ASSETS.md。欢迎带着复现步骤和去掉个人内容的截图来反馈问题。
