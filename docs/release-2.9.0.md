## 简体中文

六款《孤独摇滚》壁纸现已适配 Windows x64 上的 **Codex 26.1029.61003（安装包 26.1029.7803.0）**。

- 从托盘退出后，即使旧进程还在收尾，也可以直接从桌面快捷方式重新打开。
- 首次登录或页面加载较慢时，进入 Chat 或 Work 后壁纸会自动出现。
- 更新了图片预览、顶部渐变、输入框装饰和对话底栏的适配，继续支持 STARRY 切换与任务多窗口。

**安装或升级** 请下载 **Bocchi-Codex-Theme-2.9.0-windows-x64.zip**，完整解压到新文件夹，运行 **01-安装.cmd** 或 **Install.cmd**。保存工作，从托盘退出普通 Codex，再打开桌面的 **Bocchi Codex Theme**。暂停主题可用 **Pause.cmd**，恢复普通客户端可用 **Restore.cmd**。旧客户端 26.1023.51421 请使用 [2.8.1](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.8.1)。

## English

All six Bocchi the Rock! wallpapers now support **Codex 26.1029.61003 on Windows x64 (package 26.1029.7803.0)**.

- Reopen the desktop shortcut after a tray exit, even while the previous process is finishing up.
- If sign-in or the first page takes a while, your wallpaper appears once Chat or Work is ready.
- Image previews, the top fade, composer decorations and the conversation footer have been updated for this build. STARRY and local task windows are supported.

**Install or upgrade** by extracting **Bocchi-Codex-Theme-2.9.0-windows-x64.zip** into a new folder and running **Install.cmd**. Save your work, exit the ordinary client from the tray, then open **Bocchi Codex Theme** on the desktop. Use **Pause.cmd** to hide the theme or **Restore.cmd** to return to the ordinary client. For Codex 26.1023.51421, use [2.8.1](https://github.com/Eltamako/bocchi-codex-theme/releases/tag/v2.8.1).

The source ZIP is for development. **SHA256SUMS.txt** covers both ZIP downloads.
